## 交叉验收

1. 同一场战斗先打创世纪，再打彗星、共鸣、中子护盾、星尘和葬送：固定费用仍须满足蓝星门槛；葬送等得星效果在本回合可用，回合结束后全部得星来源被禁止。
2. 葬送复制品分别通过双持、普通复制、去除消耗及回手测试，核对每张牌的独立计数、牌组原卡和卡面同步。
3. 征服者与剑圣等现有重放来源叠加时，核对君王之剑的攻击次数与每次格挡；回合结束或状态被移除后恢复。
4. 强化熔炉在开局手牌、抽牌堆、复制品等位置分别测试自动打出的次数；新战斗重新触发，不能每回合重复自动打出。
5. 重新启动游戏并读档，检查卡池稀有度、更名、本地化文本、葬送成长与创世纪战斗状态；确认无报错、卡面溢出或错误图标。
