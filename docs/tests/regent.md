## 交叉验收

1. 同一场战斗先打创世纪，再打彗星、共鸣、中子护盾、星尘和葬送：固定费用仍须满足蓝星门槛；葬送等得星效果在本回合可用，回合结束后全部得星来源被禁止。
2. 葬送复制品分别通过双持、普通复制、去除消耗及回手测试，核对每张牌的独立计数、牌组原卡和卡面同步。
3. 征服者与剑圣等现有重放来源叠加时，核对君王之剑的攻击次数与每次格挡；回合结束或状态被移除后恢复。
4. 强化熔炉在开局手牌、抽牌堆、复制品等位置分别测试自动打出的次数；新战斗重新触发，不能每回合重复自动打出。
5. 重新启动游戏并读档，检查卡池稀有度、更名、本地化文本、葬送成长与创世纪战斗状态；确认无报错、卡面溢出或错误图标。

## 测试记录

### 2026-10-11 卡牌总览详情窗口修正

用户报告大爆炸、追踪之刃等卡牌详情未显示。游戏日志的 `CanonicalModelException` 指向 `ConquerorReplayPatch` 读取展示用君王之剑模板的 `Owner`；`BigBang.get_ExtraHoverTips → FromForge → SovereignBlade` 及 `NInspectCardScreen.UpdateCardDisplay` 调用链确认了原因。修正为读取 Owner 前确认卡牌 `IsMutable`，使 canonical 展示模板保持原重放数。

Release 编译通过（0 错误、10 条原有警告）。5 项本地数据检查通过：复现模板 Owner 异常、模板零重放、模板既有重放保留、无主可变预览保留重放、其他模板卡不受影响。独立进程中的 Harmony 挂载检查因游戏自带 Harmony 不支持该进程的 .NET 10 而未完成，不计为通过；游戏内完整显示流程仍需以下复测。

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| R09-UI1 | 在卡牌总览中悬停、点击大爆炸、追踪之刃、征服者、剑圣，以及其他有铸造提示的牌。 | 卡牌详情大图和关联卡牌／关键词提示正常出现。 |
| R09-UI2 | 在详情中切换查看升级、左右换牌、关闭再打开。 | 大图和升级效果持续正常显示，日志无该模板 Owner 异常。 |
| R09-UI3 | 战斗中重复使用征服者，再打君王之剑；下一回合再打剑，并与剑圣叠加。 | 征服者重放和回合末清除保持设计，其他来源的重放保持。 |

### 2026-10-11 葬送存档成长修正

用户报告返回标题页后继续游戏，葬送成长回归 1 蓝星。只读检查当前存档及备份发现，牌组内的葬送均没有成长字段。实现改为在 `CardModel.ToSerializable` 写入卡牌 `Props.ints` 的 `IncreasedDamage`，在 `CardModel.FromSerializable` 完成后恢复成长及动态卡面；该字段名沿用巨镰已注册的整数存档名，按每张葬送独立存储，不影响巨镰。

Release 编译通过（0 错误、10 条原有警告）。本地数据检查直接调用新版保存／加载补丁，使用真实游戏卡牌数据类型和 JSON 序列化到新建卡牌，16 项断言通过：1／2／5／6／13 蓝星及卡面恢复、连续三次保存读档、复制品独立成长、不同卡牌分别恢复、缺失字段不清除现有成长、旧字段兼容读取、重复写入不产生重复字段。这些检查不包含游戏启动和标题页流程，仍需以下复测。

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| R21-S1 | 将牌组原卡成长到 3 蓝星，结束战斗后保存并返回标题页，再继续游戏。 | 牌组卡面仍显示 3 蓝星，下一场打出获得 3 蓝星；再次斩杀后成长至 4。 |
| R21-S2 | 成长到 6 蓝星以上，分别返回标题页、完全关闭游戏再继续。 | 实际收益和数字蓝星卡面均保持保存前数值，升级及附魔也保持。 |
| R21-S3 | 牌组两张葬送分别成长到不同值，保存并继续，重复三次。 | 每张牌独立恢复，无归零、串值或重复增长。 |
| R21-S4 | 战斗复制品继承原卡后单独成长，结束战斗并保存继续。 | 牌组原卡保留自己的成长，不获得战斗复制品的额外成长。 |
