# 骨妹手工测试用例

编制日期：2026-10-20。适用游戏：v0.111.0。范围：灵魂及本轮 19 张卡牌改动，共 41 个测试用例。

当前状态：2026-10-20 作者确认**基本测试完成，可以先发布**。已单独确认 M01～M05 通过；M06 的首次闪退、提示缺失和恢复原版流程过程保留在[手工测试记录](records/2026-10-20-necrobinder-manual.md)。未逐项反馈的用例继续作为回归清单，不自动记为全部通过。本地程序检查不代替手工通过结果。

## 执行准备

1. 完全重启游戏，启用 BaseLib 与唯一的 RebalanceMod，先用简体中文测试。安装基准见[本地实现检查记录](records/2026-10-20-necrobinder-local.md)。
2. 基础数值用例关闭其他平衡 Mod；除用例明确要求外，不带力量、敏捷、虚弱、易伤、脆弱、召唤加成、额外抽牌、保留、自动打牌等修正。
3. 使用可控战斗与现有调试工具（如有）准备卡牌、敌人和牌堆。本清单不假定任何特定控制台命令；无法准备的条件记为“未执行”，不要改记“通过”。
4. 选择生命充足、无反伤和特殊死亡效果的敌人；抽牌堆至少准备 10 张普通牌。除特别说明外，玩家格挡、敌人格挡和相关负面状态从 0 开始。
5. 每个独立用例重新建立前置条件。带 `/` 的数值依次为普通版/升级版，两版分别执行，不能只观察升级预览。
6. 死亡与复活测试必须通过正常卡牌或真正的死亡、召唤命令发生。**只把生命改成 0 不等同于已经执行死亡事件**，不能据此判断计数失败。
7. 验证回合末留牌时，安排敌人不改变玩家手牌；分别记录“点击结束回合前”“回合末结算后”“下个玩家回合开始后”的手牌与牌堆。

优先级：**P0** 为首次验收必测，**P1** 为完整功能与回归，**P2** 为需要特殊环境的兼容边界。

建议顺序：M01 → N17、N06、N18、N19 → M02～M07 → N08、N15、N11 → 其余逐卡 → X 组联动 → E 组兼容。
