# 静默猎手 Mod 测试清单

本清单的空复选框表示尚未在迁移后的工作目录记录验证结果。勾选时请补充游戏版本、测试日期及必要日志。

## 测试前准备

- [ ] 完全退出游戏
- [ ] 确认游戏 `mods/RebalanceMod/` 中存在 `RebalanceMod.dll`、`RebalanceMod.json`、`RebalanceMod.pck`
- [ ] 启动游戏并使用静默者进入一场战斗
- [ ] 分别准备未升级卡牌和升级卡牌进行测试

## 卡牌功能测试

### 计算下注

- [ ] 未升级：打出后丢弃全部手牌，再抽取相同数量的牌
- [ ] 未升级：卡牌本身进入消耗堆
- [ ] 升级后：打出后丢弃全部手牌，再抽取相同数量的牌
- [ ] 升级后：卡牌本身不进入消耗堆
- [ ] 升级后：卡牌不显示保留关键词

### 腐蚀波

- [ ] 打出后获得原本的腐蚀波能力
- [ ] 本回合抽牌时触发中毒
- [ ] 每次抽牌只对一名敌人施加中毒
- [ ] 多名敌人存在时，确认不是所有敌人同时中毒
- [ ] 回合结束后能力按原机制移除
- [ ] 敌方抽牌不会错误触发玩家的腐蚀波

### 独门技术

- [ ] 卡牌在奖励或图鉴中显示为蓝卡（Uncommon）
- [ ] 卡牌原本的抽牌和本回合保留效果不变

### 全神贯注

- [ ] 卡牌出现在静默者卡池中
- [ ] 卡图正常显示，不使用占位图
- [ ] 未升级费用为0
- [ ] 未升级选择弃置3张手牌
- [ ] 手牌不足3张时可以正常弃置剩余手牌
- [ ] 弃牌完成后获得2点能量
- [ ] 升级后选择弃置2张手牌
- [ ] 升级后仍获得2点能量
- [ ] 多张牌一次性弃置，奇巧牌的回合时序正常

### 翻越撑击

- [ ] 未升级造成7点伤害
- [ ] 升级后造成9点伤害
- [ ] 原本的全体敌人攻击和奇巧效果不变

### 谋划专家

- [ ] 未升级费用为1
- [ ] 升级后费用为0
- [ ] 打出能力后，本回合第一张牌获得奇巧
- [ ] 同一回合第二张牌不会再次触发
- [ ] 下一回合第一张牌可以再次获得奇巧
- [ ] 获得的奇巧持续到本场战斗结束，不会在回合结束时消失
- [ ] 第一张牌可以是攻击牌、技能牌或能力牌
- [ ] 同一回合多个谋划专家不会导致卡牌重复获得效果

### 触不可及

- [ ] 未升级获得7点格挡
- [ ] 升级后获得9点格挡
- [ ] 卡牌原本的奇巧和费用机制不变

### 幽魂形态

- [ ] 卡牌显示固有关键词
- [ ] 卡牌显示保留关键词
- [ ] 卡牌显示奇巧关键词
- [ ] 打出后无实体效果正常生效
- [ ] 回合开始时敏捷降低效果正常生效
- [ ] 卡牌在未打出时可被保留
- [ ] 卡牌本身不会因奇巧错误进入消耗堆

## 发布与日志检查

- [ ] 游戏完全重启后模组正常加载
- [ ] `RebalanceMod` 初始化日志只出现一次
- [ ] 日志中没有 `Patching exception`
- [ ] 日志中没有 `HarmonyException`
- [ ] 日志中没有 `Could not find card image path`
- [ ] 日志中没有本地化 JSON 加载错误
- [ ] 确认 `RebalanceMod.pck` 包含全神贯注的卡牌文本
- [ ] 确认 DLL 只有一个 Mod 初始化器，并同时包含三个角色的补丁

Windows 日志通常位于 `%APPDATA%\SlayTheSpire2\logs\godot.log`。
