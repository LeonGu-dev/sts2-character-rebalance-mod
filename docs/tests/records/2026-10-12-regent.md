### 2026-10-11 卡牌总览详情窗口修正

用户报告大爆炸、追踪之刃等卡牌详情未显示。游戏日志的 `CanonicalModelException` 指向 `ConquerorReplayPatch` 读取展示用君王之剑模板的 `Owner`；`BigBang.get_ExtraHoverTips → FromForge → SovereignBlade` 及 `NInspectCardScreen.UpdateCardDisplay` 调用链确认了原因。修正为读取 Owner 前确认卡牌 `IsMutable`，使 canonical 展示模板保持原重放数。

Release 编译通过（0 错误、10 条原有警告）。5 项本地数据检查通过：复现模板 Owner 异常、模板零重放、模板既有重放保留、无主可变预览保留重放、其他模板卡不受影响。独立进程中的 Harmony 挂载检查因游戏自带 Harmony 不支持该进程的 .NET 10 而未完成，不计为通过；游戏内验证现已由用户确认完成；以下步骤保留供后续回归。

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| R09-UI1 | 在卡牌总览中悬停、点击大爆炸、追踪之刃、征服者、剑圣，以及其他有铸造提示的牌。 | 卡牌详情大图和关联卡牌／关键词提示正常出现。 |
| R09-UI2 | 在详情中切换查看升级、左右换牌、关闭再打开。 | 大图和升级效果持续正常显示，日志无该模板 Owner 异常。 |

### 2026-10-11 三处问题修正与回归用例

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| R09-F1 | 同回合打出征服者 2～3 次，再打君王之剑，结束回合后再次打剑。 | 本回合获得对应次数的额外重放；回合末征服者状态全部移除，下回合无征服者提供的重放。 |
| R09-F2 | 先有剑圣等独立重放来源，再重复打征服者并结束回合。 | 只移除征服者提供的全部重放，独立来源仍按原规则生效。 |
| R10-F1 | 牌组包含 5 张普通牌及 1 张强化熔炉，开局抽 5 张。 | 熔炉先置于抽牌堆底，开局抽到 5 张普通牌；熔炉直接从抽牌堆自动打出，不占开局手牌名额。 |
| R10-F2 | 分别测试 4 张普通牌加 1 张强化熔炉、5 张普通牌加多张强化熔炉，以及同时有原版注能牌。 | 普通牌不足开局抽牌数时，熔炉可能先进入手牌再自动打出，与原版注能一致；普通牌足够时所有强化熔炉留在堆底并各自动打出一次。 |
| R10-F3 | 同牌组混入未强化熔炉；继续第二回合或战斗中生成强化熔炉。 | 未强化熔炉不受此开场排序影响；非开场不因新增排序逻辑自动打出。 |
| R21-F1 | 用葬送击杀带爪牙状态的敌人，再将同一张牌回手打出。 | 当前蓝星收益照常结算，击杀不增加成长；本牌、牌组原卡及复制品的计数均不额外增加。 |
| R21-F2 | 用葬送击杀普通敌人，分别测试未击杀、被阻止死亡和实际击杀。 | 只有允许斩杀收益的实际击杀获得 +1 成长，且从下一次出牌开始生效。 |
| R21-F3 | 对有其他斩杀限制的敌人，与狂宴／狩猎的原版判定对照。 | 葬送遵循目标所有状态的 ShouldOwnerDeathTriggerFatal 判定，按攻击前状态判断，不局限于检查爪牙状态。 |

本轮源码核对发现：原版征服者回合末仅减 1；原版注能在首回合抽牌前置于堆底、抽牌后自动打出；狂宴及狩猎在攻击前读取目标的斩杀许可。修正已采用对应规则。用户报告的三处旧行为均已记录，修正版已纳入 2026-10-12 用户确认的游戏内验收。

### 2026-10-11 葬送存档成长修正

用户报告返回标题页后继续游戏，葬送成长回归 1 蓝星。只读检查当前存档及备份发现，牌组内的葬送均没有成长字段。实现改为在 `CardModel.ToSerializable` 写入卡牌 `Props.ints` 的 `IncreasedDamage`，在 `CardModel.FromSerializable` 完成后恢复成长及动态卡面；该字段名沿用巨镰已注册的整数存档名，按每张葬送独立存储，不影响巨镰。

Release 编译通过（0 错误、10 条原有警告）。本地数据检查直接调用新版保存／加载补丁，使用真实游戏卡牌数据类型和 JSON 序列化到新建卡牌，16 项断言通过：1／2／5／6／13 蓝星及卡面恢复、连续三次保存读档、复制品独立成长、不同卡牌分别恢复、缺失字段不清除现有成长、旧字段兼容读取、重复写入不产生重复字段。这些本地检查不包含游戏启动和标题页流程；后续游戏内验收已由用户确认完成，以下步骤保留供回归。

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| R21-S1 | 将牌组原卡成长到 3 蓝星，结束战斗后保存并返回标题页，再继续游戏。 | 牌组卡面仍显示 3 蓝星，下一场打出获得 3 蓝星；再次斩杀后成长至 4。 |
| R21-S2 | 成长到 6 蓝星以上，分别返回标题页、完全关闭游戏再继续。 | 实际收益和数字蓝星卡面均保持保存前数值，升级及附魔也保持。 |
| R21-S3 | 牌组两张葬送分别成长到不同值，保存并继续，重复三次。 | 每张牌独立恢复，无归零、串值或重复增长。 |
| R21-S4 | 战斗复制品继承原卡后单独成长，结束战斗并保存继续。 | 牌组原卡保留自己的成长，不获得战斗复制品的额外成长。 |

已丢失且没有写进旧存档的成长值无法仅凭存档还原；验收应以修正版中新增成长后保存的数值为准。
