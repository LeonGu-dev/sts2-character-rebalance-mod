# 亡灵契约师回归清单

基准：v0.111.0。2026-10-20 作者确认基本游戏内测试完成并同意先发布；下面保留完整回归清单，未勾选不代表已知失败，也不推定每个边界都已执行。实际反馈见[手工测试记录](records/2026-10-20-necrobinder-manual.md)。虚无消耗抽牌遵循金纸的延后结算方式。

需要逐步操作与具体数值时，使用[骨妹手工测试用例](necrobinder-manual.md)：41 个用例，含准备条件、步骤、预期、优先级与结果记录模板。本文件保留为快速勾选清单。

## 灵魂

- [ ] 普通版与升级版均显示 0 费、虚无、消耗，以及“被消耗时抽 2/3 张牌”；总览和升级预览一致。
- [ ] 主动打出普通/升级灵魂，原打出效果不抽牌，随后自身消耗各抽 2/3 张；只记录一次打牌与一次自身消耗效果。
- [ ] 用其他卡牌消耗灵魂，无需打出灵魂即可抽 2/3 张牌。
- [ ] 留下多张灵魂并结束回合，每张虚无消耗各触发一次，不因其他灵魂在场重复抽牌。
- [ ] 保留多张灵魂时测试手牌上限，抽到手满即停；禁止抽牌效果正常阻止灵魂抽牌。
- [ ] 对打牌次数限制分别测试主动打出与被动消耗：主动打出仍计数，被动消耗不增加打牌次数。
- [ ] 非灵魂卡牌消耗不触发灵魂抽牌；原有战鼓和其他消耗响应正常。
- [ ] 骨妹以外角色获得灵魂时同样适用新效果；多人游戏中只为该灵魂所属玩家抽牌。
- [ ] 混合普通与升级灵魂及普通手牌结束回合：原有普通手牌先弃掉，之后每张灵魂各抽 2/3 张，抽入的牌留在手中。
- [ ] 令延后抽牌抽到进阶之灾、另一张灵魂或带手牌回合末效果的牌：本回合不再消耗、不触发其回合末效果、不弃掉；下回合正常处理。
- [ ] 下回合正常抽牌叠加至已有手牌，遵循上限；新牌没有额外保留关键词，下个回合末正常弃牌或虚无消耗。
- [ ] 携带金纸并积累到触发阈值，金纸与灵魂各正常抽牌，没有重复结算或新增虚无消耗。
- [ ] 在额外回合、多人不同玩家回合及战斗结束时检查延后状态，不提前结算、不跨战斗残留。

- [ ] 骨舞存活分支单体攻击 4/6，无抽牌；死亡/缺失分支无需选敌，改为召唤 4/6，不攻击。

- [ ] 起床气两版费用 2/1，复活时各获得 1 张普通扫荡凝视；首次召唤、存活时增血、召唤被阻止均不生成。
- [ ] 亡魂牵引两版费用均为 1，死亡抽 1/2，只响应能力生效后的己方奥斯提死亡；多层按层数抽牌，不重复计数。
