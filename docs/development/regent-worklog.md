# 储君开发记录

记录日期：2026-09-27。来源：用户提供的设计方案及后续澄清。已核对本机游戏 v0.111.0。下表 `基础/强化` 表示未强化/强化后的数值。21 项均已实现并编译。2026-10-12 用户确认储君全部改动已完成游戏内验证；验收记录及后续回归用例见 [测试清单](../tests/regent.md)。

## 初步分类

按设计改动范围分类，**不代表已核实代码实现难度**。费用、蓝星、稀有度及升级分支的变化归入「简单改动」；替换核心结算或需要跨回合、跨战斗机制的变化归入「重做」。

| 类别 | 数量 | 卡牌及编号 | 分类依据 |
| --- | ---: | --- | --- |
| 纯数值修改 | 6 | 碰撞轨迹 R01、宇宙冷漠 R05、招架 R11、君权自授 R12、星灭 R14、抉择，抉择 R15 | 只改伤害、格挡、力量降低值或抽牌数；效果结构不变。 |
| 简单改动 | 8 | 何人僭越 R02、辉光 R03、秘密藏品 R04、地形改造 R07、共鸣 R08、新生之喜 R17、武器库 R18、中子护盾 R19 | 调整关键词、稀有度、费用、蓝星数值、收益时点或升级时生成的牌；不设计新的持续性战斗规则。 |
| 重做／核心机制替换 | 7 | 伽马爆破 R06、征服者 R09、熔炉 R10、彗星 R13、既定事项→命定胜利 R16、创世纪 R20、葬送 R21 | 替换主要效果或引入重放、自动打出、X 蓝星特殊结算、跨战斗成长等机制。 |

「征服者」与「熔炉」并非整张卡从零设计，而是因升级／核心效果改为不同机制，暂放重做档；后续核对游戏源码后可再调整实施批次。

## v0.111.0 源码分析

已核对本机游戏 `release_info.json` 为 v0.111.0，参考源码与该安装版本一致。以下只记录对实施有影响的发现，目标仍以上方设计表为准。

| 范围 | 核对结果与实施关注点 |
| --- | --- |
| R01、R05、R11、R12、R14、R15 | 都已有相应动态数值。R14 的力量削减由独立变量控制，保留原有「本回合」与全体敌人范围。R15 当前源码的抽牌数实际为 **3/5**，方案目标为 **2/4**；原文中的「3/6」与安装版本不一致。 |
| R02 | 当前为给予虚弱 1、易伤 1，基础与强化均消耗；原强化效果仅移除消耗。目标可明确为强化后消耗仍在，两项效果各升至 2。 |
| R03、R04 | R03 当前获得 1/2 蓝星、立即抽 1、下回合抽 1；目标应只增加立即抽牌并改稀有度，保留蓝星收益。R04 当前游戏内名为「隐秘藏品」(`HIDDEN_CACHE`)，收益为本回合 1、下回合 3/4；目标的 2+2/2+3 与原总量一致。 |
| R07、R08、R17、R18、R19 | 稀有度、蓝星费用、能量费用及升级生成牌可在现有卡牌机制上调整。R17 原为生成 3/4 张无色牌；目标强化后为生成 3 张升级的无色牌。R18 升级后原本获得固有，方案未要求移除。 |
| R06 | 原为 0 费、3 蓝星、单体伤害并给予负面状态；目标改为 1 费、2 蓝星、按消耗手中无色牌的张数逐次打击全体敌人，需替换主要出牌逻辑及目标范围。 |
| R09 | 原为铸造 3/5，然后给指定敌人施加本回合君王之剑双倍伤害。`SwordSagePower` 已有给当前及后续君王之剑添加重放的机制；目标状态施加给自己、回合末移除，复用原征服者状态图标。君王之剑每次出牌的格挡在攻击结算后发生，因此重放可再次触发格挡。 |
| R10 | 熔炉是能力牌，原效果为每回合开始铸造 5/7。原版 `Imbued`（注能）只允许附魔技能牌，直接给熔炉附上原版注能会被拒绝。用户确认保留能力牌，用同一自动出牌时机与逻辑实现强化后的开场自动打出；只在强化卡面增加文字，不修改原版注能。 |
| R13 | 原为 0 费、5 蓝星、33/44 单体伤害并给予 3 层虚弱与易伤。目标仍为 0 费、5 蓝星，改为 18/23 伤害后获得 5 蓝星；强制打出等不花蓝星的情形会净赚 5 蓝星。 |
| R16 | 原为 1 费技能、下回合从抽牌堆选择 2/3 张牌。目标换为能力牌并读取当前 `VigorPower` 层数，再给予等量力量、移除活力；卡牌名和描述需更新，卡图保留。 |
| R20 | 原为 2 费能力，每回合开始获得 2/3 蓝星。现有 X 蓝星牌如「星尘」通过 `LastStarsSpent` 计算 X；若只阻止扣费，X 会成为 0。需在免耗蓝星期间保留打出瞬间的持有量作为 X，同时保持固定蓝星牌的可打出门槛；回合末清空并拦截后续所有蓝星来源。 |
| R21 | 原为 1 费、4 蓝星、35/45 伤害的蓝卡。目标改为 2 费、无蓝星费用、10/14 伤害的金卡。`TheScythe`（巨镰）展示了单张卡及其 `DeckVersion` 的跨战斗持久成长；事件牌「双持」使用 `CreateClone()`，复制时继承当前字段，之后应独立成长。原版 `starIcons` 只重复绘制蓝星图标，超过 5 的数字蓝星需要另做动态显示。 |

## 修复记录与回归重点

### 2026-10-11 游戏内反馈修正

2026-10-12 用户确认储君改动已全部完成游戏内验证。以下修复均纳入当前验收，详细记录与后续回归步骤见 [测试清单](../tests/regent.md)。

- R09：重复打出征服者时，所有征服者层数在所属角色回合结束时一起移除；只移除该状态提供的重放，保留剑圣等独立来源。
- R10：补齐原版注能的开局堆底排序，在第一回合的常规手牌抽取之前将所有强化熔炉置于抽牌堆底；仍在原自动出牌阶段打出。普通牌不足开局抽牌数时，允许先抽到熔炉再自动打出，与原版规则一致。
- R21：斩杀成长采用狂宴／狩猎的判定，在攻击前读取目标所有状态的 `ShouldOwnerDeathTriggerFatal()`；爪牙及其他不允许斩杀收益的敌人不增长，打出时的蓝星收益照常结算。
- 上述修正已编译，并获用户游戏内验证通过；详细回归步骤见 [测试清单](../tests/regent.md)。
- R21 存档补充修正：用户报告返回标题页后成长归零，当前存档及备份无成长字段。改为在卡牌直接保存／加载入口写入、恢复每张牌的成长，避开可能被内联的 `SavedProperties.From` 包装方法；沿用巨镰注册的 `IncreasedDamage` 存档字段，16 项 JSON 数据往返断言通过，游戏内验证已由用户确认完成。
- R20 描述图标修正：中英文卡面及创世纪状态提示中的资源名称使用原生 `{singleStarIcon}` 图标，已重新打包并安装本地化资源。
- R09 总览预览修正：日志确认重放补丁读取展示用君王之剑模板的 Owner，导致大爆炸等含铸造关联提示的卡牌详情中断。读取所属玩家前先检查 `IsMutable`，使模板保持原重放数；编译和 5 项本地数据检查通过，游戏内验证已由用户确认完成。

以下机制保留作为后续修改或游戏更新时的回归重点：

- **卡牌与资源定位**：核对 21 张卡在当前游戏版本中的 ID、稀有度、升级分支、费用、效果顺序及本地化键。
- **触发与结算**：核对「君王之剑」的重放与格挡触发、消耗手牌无色牌的逐次范围伤害、自动打出附魔、X 蓝星牌被强制打出时的 X 值。
- **状态与生命周期**：核对「创世纪」仅本回合免除蓝星消耗、回合末清空与本场战斗禁获蓝星的先后顺序，以及「葬送」斩杀成长如何在本局游戏中持续并更新所有相关卡面。
- **展示**：核对更名与卡图沿用、稀有度资源、蓝星数值超过 5 时的动态卡面表示。
- **表述约定**：「何人僭越」的 2 层按易伤、虚弱各 2 层解读；「葬送」的「本局游戏」按牌组原卡跨战斗保留解读。

当前 21 项改动均已实现、编译并通过用户游戏内验证。后续改变机制或升级游戏版本时，按以上分组重新回归并记录结果。
