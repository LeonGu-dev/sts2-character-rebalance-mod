# 故障机器人 (Defect) 卡牌改动汇总

记录来源：迁移前的调整汇总；后续实现以本仓库代码为准。原记录对应的游戏版本为 v0.111.0，更新游戏后须重新验证。

- **吞噬暗影**:重做。稀有 2 费能力,不再充球;效果:你激发黑暗充能球后,获得其未被格挡伤害的 50%(未强化)/100%(强化)作为格挡。
- **冷却剂**:重做。稀有 1 费能力。打出攻击牌后获得 1 颗临时冰霜球(回合末触发冰霜被动+2格挡,下回合开始直接消失、不激发);升级获得固有。
- **漆黑**:被动触发恒 1 次(升级不再 2 次);未强化获得消耗,强化去掉消耗。
- **回收**(内存清理 Scavenge):重做。1/0 费罕见技能,重命名为"回收"。消耗一张牌,获得与其当前费用相等的能量。
- **压缩**(衍生牌"燃料"):燃料由获得 1/2 能量改为抽 1/2 张牌。
- **散射炮**:伤害由 8/11 降低为 7/10。
- **冰川**:格挡由 6/9 提高为 7/10。
- **热修复**:重做。0 费普通,获得 2/3 点临时集中;每次使用后,本回合费用+1;不再消耗。
- **冰之长枪**:重做。改为罕见、1 费。激发所有冰霜充能球,每激发一颗对随机敌人造成 6/9 点伤害；冰霜球原有的激发格挡仍正常生效。
- **引雷针**:重做。1 费能力牌,打出时一次性激发所有闪电充能球;闪电 Evoke 伤害照常,每激发一颗额外获得 2/3 点荆棘。
- **玻璃工艺**:重做。移除格挡;生成 1 颗玻璃充能球,并为所有玻璃充能球计数+1/2。
- **模组改造**:打出后本牌本局费用+1 改为本回合费用+1。
- **雷霆**:效果由 8/11 降低为 6/8。
- **折射**:重做。稀有、3 费能力。将要受到伤害时,激发一颗计数不为 0 的玻璃充能球并阻止此伤害;升级后打出时额外生成 1 颗玻璃充能球。
- **充电**:格挡由 7/10 提高为 8/11。
- **碎片整理**:稀有度由稀有(Rare)降低为罕见(Uncommon)。
- **偏差认知**:新增固有、保留。
- **递归**(新增):1/0 费罕见技能。激发你最右边的充能球,然后生成一个与被激发球完全相同(含计数)的充能球。
- **散热片**(新增):1 费罕见能力。每当你打出一张能力牌,抽 1/2 张牌。
