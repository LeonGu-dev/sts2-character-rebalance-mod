# 2026-10-20 更新：亡灵契约师

适用游戏：Slay the Spire 2 **v0.111.0**。构建依赖：**BaseLib 3.4.5**。本次发布将亡灵契约师纳入统一 Mod，五角色共 **83 项卡牌改动**，包含 4 张新增卡。

## 玩法重点

### 灵魂：从打出抽牌改为消耗抽牌

- 0 费，虚无、消耗；打出本身没有效果，被消耗时抽 2/3 张牌。
- 主动打出仍计入打牌次数，但由其他效果或虚无消耗时不额外计入打牌次数。
- 回合末虚无消耗引起的抽牌在弃牌后执行。新抽到的牌留到下回合，本回合不会再次处理其虚无或手牌回合末效果。
- 抽牌遵循原版手牌上限、禁止抽牌及相关反馈，不绕过小提琴等限制。

### 奥斯提：死亡与复活成为构筑资源

- **亡魂牵引**：1 费罕见能力，奥斯提死亡时抽 1/2 张牌。
- **苦难**：1 费罕见能力，奥斯提死亡时对全体造成 7/11 点能力伤害。
- **起床气**（原哨卫模式）：2/1 费稀有能力，奥斯提复活时将一张普通扫荡凝视加入手牌；首次召唤、存活时增加生命不算复活。
- **化我血骨**（原死亡之门）：1 费能力，按本场己方奥斯提已经死亡的次数一次性回复生命，每次 1/2 点，最多 6/9 点；不在之后持续回血。

### 新的召唤、变化与灾厄联动

- **骨舞**（原取回）：0 费罕见攻击，奥斯提造成 4/6 点伤害；已死亡或缺失时改为召唤 4/6。
- **鬼火**：0 费普通技能，召唤 4/6，不再消耗或保留。**死者苏生**在奥斯提已死亡或缺失时额外召唤一次。
- **切断**：奥斯提死去，将手中非攻击牌变化为灵魂/灵魂+；每张实际变化获得 2/3 格挡并分别给予自身 3/2 灾厄。变化不等于消耗。
- **献祭仪式**（原忧郁）：给予所有敌人等于奥斯提现有生命的灾厄，然后奥斯提死去。
- **灵魂诅咒**（原吞噬生命）：打出灵魂时给予全体 1/2 灾厄；虚无消耗不触发。**灰烬之灵**分别响应打出和消耗虚无牌，各获得 3/4 格挡。
- **女妖之嚎**：2 费，全体单段伤害为 16/20 加奥斯提现有生命，随后奥斯提死去，并施加本场无法召唤的负面状态；人工制品可抵消该状态，但不会撤销伤害与死亡。
- **捕捉灵魂**：全体失去 3/4 生命；按结算前存活敌人数，每名对应召唤 2/3 并获得一张普通灵魂入手。

坟冢爆射、剥夺、违逆、吸引仇恨、得力助手、摧残等数值调整及全部升级效果，见[完整逐卡对照](card-changes-zh.md)。

## 安装与更新

完全退出游戏，将同一构建的 `RebalanceMod.dll`、`RebalanceMod.json`、`RebalanceMod.pck` 放入 `mods/RebalanceMod/`。启用 BaseLib 和本 Mod，不要同时启用旧的分角色版本。安装与从源码构建步骤见[项目首页](../../README.md)。

本次推送发布源码与说明文档，不等于创建 GitHub 二进制 Release 或更新 Steam 工坊。下载入口以实际发布渠道为准。
