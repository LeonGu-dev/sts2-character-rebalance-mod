# 角色平衡 | Rebalance

> Mod 说明页草稿，依据当前仓库代码与卡牌文本整理。适用的已验证游戏版本：**Slay the Spire 2 v0.111.0**。数值中的“前 / 后”分别表示未升级 / 已升级。

这是一个同时调整**铁甲战士、静默猎手和故障机器人**的单一 Mod。它修改部分原版卡牌的数值、费用、稀有度和机制，并为三个角色加入共四张新卡。卡牌文本提供简体中文和英文。

## 铁甲战士

| 卡牌 | 改动 |
| --- | --- |
| 好勇斗狠 | 升级不再获得固有，改为降低 1 点费用（1 → 0）。 |
| 烙印 | 获得的力量为 1 / 1；升级后额外抽 1 张牌。 |
| 与我一战 | 先获得 2 / 3 点力量，再造成两次伤害，最后给予敌人力量；升级不再增加伤害。 |
| 熔融之拳 | 伤害调整为 8 / 12。 |
| 破击 | 伤害调整为 15 / 20，施加易伤 5 / 7。 |
| 灰烬打击 | 消耗堆中每张牌提供的额外伤害由 3 / 4 调整为 2 / 3。 |
| 巨像 | 格挡调整为 6 / 9；本回合易伤敌人对你造成的伤害降低 25%；稀有度改为普通。 |
| 黑暗之拥 | 稀有度改为罕见。 |
| 主宰 | 施加 2 层易伤；升级改为降低 1 点费用。 |
| 巩固 | 加入铁甲战士卡池，稀有度为罕见。 |
| 腐化 | 升级改为获得固有，费用保持 3 点。 |
| 焚烧 | 重做为 2 费、具有消耗的攻击牌：消耗手牌中的所有攻击牌；每消耗一张，对所有敌人造成 6 / 8 点伤害，并失去 1 点生命。 |
| 绯红披风 | 升级后回合开始时不再失去生命，仍获得 7 点格挡。 |
| 战鼓 | 每次打出后，本回合这张牌的费用增加 1；升级后初始费用为 0；移除被消耗时获得能量的效果。 |
| 被遗忘的仪式 | 改为具有消耗的攻击牌：造成 8 / 11 点伤害；若本回合消耗过牌，获得 3 / 4 点能量。 |
| 痛殴 | 改为单次 8 点基础伤害；消耗手牌中的一张攻击牌，并将其伤害添加给痛殴。未升级时随机选择，升级后可自行选择。 |

**新增卡牌：硬撑**——1 费罕见技能，获得 15 / 20 点格挡，并将 2 张伤口加入手牌。

## 静默猎手

## 故障机器人

| 卡牌 | 改动 |
| --- | --- |

| 冷却剂 | 重做为 1 费稀有能力。每打出一张攻击牌，生成一颗临时冰霜球；它在回合结束时正常触发被动，并在下回合开始时消失，不触发激发效果。升级后获得固有。 |
| 漆黑 | 生成一颗黑暗球，并让所有黑暗球的被动触发一次；未升级时具有消耗，升级后移除消耗。 |
| 回收（原“内存清理”） | 重做为 1 / 0 费罕见技能：消耗手牌中的一张牌，获得与其当前费用相等的能量。 |
| 燃料（由“压缩”生成） | 效果改为抽 1 / 2 张牌。 |

| 冰川 | 格挡调整为 7 / 10。 |
| 热修复 | 改为 0 费技能，获得 2 / 3 点临时集中；每次打出后，本回合这张牌的费用增加 1；移除消耗。 |
| 冰之长枪 | 重做为 1 费罕见攻击：激发所有冰霜球；每激发一颗，对随机敌人造成 6 / 9 点伤害。冰霜球原有的激发格挡仍会生效。 |
| 引雷针 | 重做为 1 费罕见能力：激发所有闪电球；每激发一颗，获得 2 / 3 点荆棘。闪电球原有的激发伤害仍会生效。 |

| 雷霆 | 激发闪电球后的追加伤害调整为 6 / 8。 |
| 折射 | 重做为 3 费稀有能力：将要受到伤害时，激发一颗计数大于 0 的玻璃球并阻止此次伤害；升级后打出时额外生成一颗玻璃球。 |
| 充电 | 格挡调整为 8 / 11。 |
| 碎片整理 | 稀有度改为罕见。 |
| 偏差认知 | 增加固有和保留，原有效果不变。 |

**新增卡牌：递归**——1 / 0 费罕见技能，激发最右边的充能球，再生成一颗与其相同的球；黑暗球和玻璃球的计数会保留。

**新增卡牌：散热片**——1 费罕见能力；每当你打出能力牌，抽 1 / 2 张牌。刚打出的散热片不触发自身，已有的散热片会正常触发。

## 安装与兼容

- 需要 **BaseLib 3.4.5 或更新版本**。本 Mod 会影响游戏玩法。
- 当前三个角色的改动都包含在一个 `RebalanceMod` 中；请不要同时启用此前按角色拆分的旧版 Mod。
- 更换 Mod 文件后请完全退出并重启游戏。游戏更新后，建议重新核对卡牌效果与兼容性。
